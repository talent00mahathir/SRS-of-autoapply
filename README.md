# SRS of AutoApply

This repository contains the Software Requirements Specification (SRS) for the AutoApply project.

## Technologies
- Documentation: Microsoft Word

## Collaboration Workflow
We follow a Pull Request-based workflow to ensure high quality and review of all changes.

1. **Clone the repository** (if you haven't already).
2. **Create a new branch** for your work:
   - `feature/<feature-name>` for new sections or features.
   - `fix/<fix-name>` for corrections.
   - `docs/<doc-name>` for documentation updates.
3. **Commit** your changes with clear messages.
4. **Push** your branch to the remote repository.
5. **Open a Pull Request** against the `main` branch.
6. **Review and Merge**: After approval, the Pull Request will be merged into `main`.

Please do not push directly to the `main` branch.
